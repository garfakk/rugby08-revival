# Shirt name fonts

Fonts for the players' names on the back of the shirts (team editor →
*Shirt names*, `src/shared/shirt_names.py`). All are from Google Fonts,
under the SIL Open Font License 1.1 (texts in `licenses/`).

| Name in the editor | File | Style used |
|---|---|---|
| Barlow Condensed (default) | BarlowCondensed-ExtraBold.ttf | ExtraBold |
| Oswald | Oswald-Variable.ttf | Bold |
| Anton | Anton-Regular.ttf | |
| Bebas Neue | BebasNeue-Regular.ttf | |
| Saira Condensed | SairaCondensed-Bold.ttf | Bold |
| Teko | Teko-Variable.ttf | SemiBold |
| Graduate | Graduate-Regular.ttf | |
| Alfa Slab One | AlfaSlabOne-Regular.ttf | |
| Russo One | RussoOne-Regular.ttf | |
| Black Ops One | BlackOpsOne-Regular.ttf | |

A team can use its own font: put the `.ttf`/`.otf` file anywhere in the team
folder and it appears in the font list.
