## Introduction
*Rugby 08 Revival* is a complete redesign of Rugby 08 with a brand new interface and extra features. It keeps only the core of the orignal game (the match itself), all the rest is redesigned and fully configurable, which means that you can have:
- Unlimited number of teams
- Unlimited number of players
- Unlimited number of tournaments
- Different seasons for each teams/players/tournaments
- Extra kits (third kit etc)
- Full customization of the match parameters (ball, logos, textures, kickoff...)
- Per player customization: tatoo, baselayer, strap, gloves, boots

The possibilities are infinite, and future updates will include:
- Extra difficulty modes
- Improved gameplay
- Tournament mode with dynamic evolution of the players based on their performance in match
- Completely new career mode
- And much more!

## Current status
Please note that it is still in development, so expect to find bugs.
The kits/heads/textures used are from [MUP Patch 2009](https://www.therugbyforum.com/threads/mup-v-1-2-season-2008-09.15872), [TRF Patch 10](https://www.therugbyforum.com/threads/trf-rugby-10-patch.18881) and [jim546](https://github.com/jimw546/jimw546-s-Rugby-08-stuff)'s creations for this demo, a big thanks for their work.

## Installation
You can find the installer exe in the releases. Alternatively you can run the program directly with python, detailed instructions will be published soon.
To install the mod you need to have a working version of Rugby 08 installed on your computer (with no mods installed). The mod only works with the no-cd executable.
The compatibility with other utilities (dgVooDoo, dxWnd etc) is not tested, contact me if you experience problems with it.
